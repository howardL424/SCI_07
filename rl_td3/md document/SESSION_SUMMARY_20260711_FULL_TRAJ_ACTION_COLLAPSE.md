## 2. 动作空间与物理含义（便于后续对话对齐）

归一化动作 `[γ_n, wT_n, wE_n] ∈ [-1,1]³`，反归一化（与 `evasion_env.py` / `env_step.m` 一致）：

```text
γ  = γ_n × 3                         → [-3, 3]
wT = 10^(wT_n × 1.5 + 3.5)           → [1e2, 1e5]
wE = 10^(wT_n + 3)                   → [1e2, 1e4]   # 即 10^(wE_n + 3)
```

进入制导律前：

```matlab
W = 1e4;
w1 = W / (1 + exp(-gamma));
w2 = W * exp(-gamma) / (1 + exp(-gamma));
% 再调用 computeOptimalCmd_duo_target(..., w1, w2, wT, wE, dstar)
```

要点：`γ, wT, wE` 是式47最优制导里的**连续权重旋钮**，不是推力开关；真正输出过载 `a_M` 是「给定权重下的最优指令」。

贴边判定（本次探测）：归一化 `|a_n| ≥ 0.99`。

## 4. 追问：三个参数都贴一边，算正常 bang-bang 吗？

### 4.1 用户观点

能理解 bang-bang（很多最优控制是 bang-bang），但质疑：**三维同时钉死一边**是否合理。

### 4.2 结论（本次对话共识）

**不太正常。** 更像 TD3 Actor **边界饱和 / 策略坍塌**，不是 PMP 意义上的最优 bang-bang。

理由：

1. **控制结构不对口**  
   经典 bang-bang 要求控制量在 Hamiltonian 中线性出现。此处动作是制导权重，不是线性 bang 控制；专家也把它们当连续调度用。

2. **合理的「bang 味」通常长这样**  
   - 按状态切换（有切换面），不是多数轨迹整段常数；  
   - 往往只有部分维极端（例如某段 `γ→±3` 全力偏一侧防御弹说得通）；  
   - 其它维仍用中间权衡（专家 `wT/wE` 正是如此）。

3. **与专家分布严重不符**（见第 5 节）  
   专家几乎从不走 TD3 主模式 `(γ≈3, wT≈1e5, wE≈1e2)`。

4. **为何成功率仍约 69%**  
   极端权重仍能给出「可用」的 `a_M`（粗启发式：几乎只防一侧 + 极重打击 + 极轻能量），任务不崩到 0；但这是**退化启发式还能打**，不是学到了专家式权重调度。

## 7. 一句话结论（给下一对话）

1. **全段也坍塌**：20 条完整轨迹、1106 步，γ/wT/wE 贴边率均为 100%；多数轨迹整段常数 `[3, 1e5, 1e2]`。  
2. **不是健康 bang-bang**：权重型动作 + 专家几乎 0% 命中该角点 + 多数无切换，符合 Actor 饱和，而非最优 bang-bang。  
3. **专家依据可靠**：对比数据来自同一套 `expert_lib_1000.mat` 的 `expert_sa` 三列动作，与训练 BC 同源。  
4. **任务指标有迷惑性**：~69% 双防+打击成功不代表策略已学到内部调度；动作空间内部基本未使用。
