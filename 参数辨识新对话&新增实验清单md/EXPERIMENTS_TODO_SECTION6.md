# 第6章补充实验清单（投稿前执行）

## 1. 使用目的

本文的核心是“双NCV三维一体化规避—目标到达制导律及其BC-TD3权重调度”，在线参数辨识仅用于增强含噪条件下的鲁棒性。因此：

- 实验篇幅和论证顺序必须以制导律、BC-TD3和规避—到达—能耗权衡为主。
- 参数辨识只做能够闭合证据链的最低充分验证，不单独扩展成大型实验章节。
- 所有方法必须尽量使用相同初始条件、随机种子和噪声序列，进行配对比较。
- 禁止编造、平滑或沿用占位数据。当前第6.3节的噪声成功率，尤其`96.7% / 96.0%`，是临时占位值，必须由真实仿真替换，并同步更新摘要、引言、正文和结论。

- [ ] P1-1：增加去除交叉耦合项的解耦制导律消融。

### P0-2 增加固定权重制导消融

**目的：** 证明在线BC-TD3权重调度确实优于固定经验权重，而不只是优于较弱的PN和正弦机动。

**最小对比组：**

1. 仅对目标PN；
2. 正弦程序机动；
3. 一体化制导律＋固定权重；
4. 一体化制导律＋纯TD3；
5. 一体化制导律＋BC-TD3。

- [ ] 固定权重应在训练集或单独验证集上确定，不能使用测试集调参。
- [ ] 说明各基线的参数如何选取，并尽量给予相同调参预算。
- [ ] 所有方法使用相同蒙特卡洛初始条件。

**验收标准：**

- 能回答“BC-TD3权重调度相对于固定权重究竟改善了什么”。
- 至少同时比较联合成功率和控制能耗。



### P0-3 增加与性能指标一致的统计量

**目的：** 直接支撑论文关于“避免过度规避、保证目标到达并降低能耗”的核心结论。

每种方法至少统计：

- [ ] 双NCV最小规避距离：`min(r_AD1,min, r_AD2,min)`。
- [ ] 终端目标误差：`r_AT,end`。
- [ ] 控制能量：`J_u = integral(||u_A||^2 dt)`。
- [ ] 双NCV规避成功率。
- [ ] 联合任务成功率：双NCV规避成功且`r_AT,end <= 10 m`。

可选统计：

- [ ] 峰值法向过载。
- [ ] 过载饱和持续时间或饱和步数比例。

**报告方式：**

- 连续指标优先报告中位数与四分位区间；分布近似对称时可补充均值与标准差。
- 成功率给出95%置信区间。
- 当前表中的“目标到达成功率（规避成功＋到达成功）”应更名为“联合任务成功率”；若需要单独的目标到达成功率，则另列一列。
- 小于约3个百分点的成功率差异不要直接写成“显著提升”，除非配对统计检验支持。

**低成本长尾性能验证（P0必做，不新增训练）：**

- [ ] 复用同一批配对蒙特卡洛逐样本结果，比较TD3与BC-TD3的尾部性能。
- [ ] 在现有性能表中增加终端误差的P95和最差5%均值（CVaR95）；若版面允许，再给出安全裕度的P5。
- [ ] 增加一张TD3与BC-TD3终端误差的经验CDF或对数CCDF图，优先使用同一坐标图，不为每项指标单独作图。
- [ ] 终端误差分布应在“两种方法均成功规避双NCV”的共同场景子集上比较，并注明该子集样本数；全样本仍单独报告联合任务成功率。
- [ ] 单个最大误差只作为补充描述，不单独用最大值证明长尾改善。
- [ ] 若BC-TD3仅在P95或CVaR95上明显优于TD3，而均值和成功率接近，应将结论准确表述为“降低尾部风险/改善困难场景性能”，不写成整体全面显著提升。

**验收标准：**

- 实验结果与论文目标函数中的规避、到达和能量三部分逐一对应。
- 能判断BC-TD3与TD3成功率接近时，BC-TD3是否减少了少数场景中的大终端误差。



### P0-4 完成真实的含噪鲁棒性与最低充分辨识验证

**目的：** 证明辨识模块确实改善了制导律所需参数的估计，并由此恢复含噪闭环性能。

**配对闭环对比：**

使用现有无噪声训练得到的TD3和BC-TD3策略，完成以下四组`2×2`配对实验：

1. TD3＋含噪解析参数，即“TD3、无辨识”；
2. TD3＋稀疏FF-RLS，即“TD3、带辨识”；
3. BC-TD3＋含噪解析参数，即“BC-TD3、无辨识”；
4. BC-TD3＋稀疏FF-RLS，即“BC-TD3、带辨识”。

- [ ] 四组必须使用相同初始条件和相同噪声实现。
- [ ] 四组均冻结现有策略参数，不进行含噪再训练，以免将“噪声训练收益”与“辨识器收益”混合。
- [ ] Actor输入必须采用该实验中真实可获得的含噪或滤波量测，不能只让制导矩阵受到噪声影响而继续向Actor输入无噪声真值。
- [ ] 比较第1组与第2组、第3组与第4组，分别判断辨识器对TD3和BC-TD3的作用。
- [ ] 比较第1组与第3组、第2组与第4组，分别判断无辨识和带辨识条件下行为克隆的作用。
- [ ] 生成真实蒙特卡洛结果，替换当前全部占位成功率。
- [ ] 保存逐样本结果，而不只保存汇总成功率，以便进行配对检验。
- [ ] 报告联合成功率、最小规避距离、终端误差和控制能量。
- [ ] 使用配对bootstrap置信区间或McNemar检验评估成功率差异。

**最低充分的直接辨识验证：**

- [ ] 利用仿真真值计算一个统一的参数估计误差，例如缩放域参数NRMSE或矩阵归一化Frobenius误差。
- [ ] 比较“含噪解析参数”和“稀疏FF-RLS估计参数”的误差。
- [ ] 至少展示一条代表性轨迹中一个NCV通道的真值与估计值；可选择`\dot Q_2`、`B_{1,2}`、`B_{2,2}`和`C_{12}`中的2至4项。
- [ ] 对估计初始瞬态作说明，必要时分别报告全程误差和去除初始化阶段后的稳态误差。

**篇幅限制：**

- 参数辨识验证控制在“一张紧凑图＋一张小表”以内。
- 放在第6.3节末尾，使用段落标题即可，不新增第6.4节。

**验收标准：**

- 能同时回答“估计是否更准”和“闭环任务是否因此改善”。
- 不将辨识模块表述为本文的主要贡献或主要性能来源。

## 4. P1：最好完成



### P1-1 去除交叉耦合项的制导律消融

**目的：** 直接验证双NCV与目标三通道交叉耦合项的必要性，这是解析制导律的关键理论贡献。

- [ ] 构造去掉非对角交叉耦合项的解耦版本，其他参数保持一致。
- [ ] 与完整`3×3`耦合制导律进行配对蒙特卡洛比较。
- [ ] 报告联合成功率、控制能量以及两个NCV最小距离的不平衡程度。
- [ ] 选择一个交叉耦合明显的代表场景展示轨迹或距离曲线。

**验收标准：**

- 能证明完整耦合模型相对于独立处理两枚NCV或简单叠加具有实际收益。



### P1-2 多随机种子训练曲线

**目的：** 支撑“行为克隆提高学习效率和训练稳定性”的结论。

- [ ] TD3和BC-TD3至少各运行5个独立训练种子。
- [ ] 绘制平均回报及标准差或置信区间阴影。
- [ ] 横轴明确为环境步数，并统一标注`×10^3`或真实步数。
- [ ] 报告达到预定回报或成功率阈值所需的训练步数。
- [ ] 检查当前图中BC-TD3早期回报低于TD3的现象；若真实结果仍如此，不得声称BC提高了早期收敛速度。

**验收标准：**

- “收敛更快”或“训练更稳定”的文字结论具有跨随机种子的统计依据。



### P1-3 BC-only消融

**目的：** 区分行为克隆初始化和TD3微调各自的作用。

**对比组：**

1. 纯TD3；
2. 仅BC预训练、未经TD3微调；
3. BC-TD3。

- [ ] 使用相同测试集比较联合成功率、终端误差和能耗。
- [ ] 若篇幅有限，可以只增加一行结果，不增加新图。

**验收标准：**

- 能说明TD3微调是否确实改善了专家模仿策略的泛化性能。



### P1-4 多档噪声强度鲁棒性

**目的：** 避免仅凭单一噪声点宣称鲁棒性。

- [ ] 至少设置低、中、高三档噪声，例如标称噪声的`0.5×、1.0×、1.5×`。
- [ ] 每档均进行“无辨识 vs 带辨识”的配对测试。
- [ ] 绘制联合成功率或性能退化量随噪声强度变化的曲线。
- [ ] 不必对所有基线重复三档测试，可只比较BC-TD3无辨识与带辨识。

**验收标准：**

- 能说明辨识模块在哪些噪声强度范围内有效，以及是否存在失效边界。



### P1-5 条件触发：含噪训练TD3与BC-TD3

**触发条件：** 仅当P0-4中“现有无噪声训练策略＋稀疏FF-RLS辨识器”仍出现明显性能下降、随机种子间波动过大，或无法支撑论文的鲁棒性结论时实施。若P0-4结果已经稳定且满足论文需要，则可以不做本项。

**目的：** 判断Actor输入端的测量噪声是否已成为主要瓶颈，并通过含噪强化学习提高最终闭环性能。

- [ ] 分别重新训练含噪TD3和含噪BC-TD3，二者采用相同噪声分布、训练步数、随机种子数量和网络超参数。
- [ ] 两种算法训练时均将稀疏FF-RLS辨识器放入闭环，使训练链路与最终部署链路一致。
- [ ] BC-TD3继续使用现有无噪声专家轨迹完成BC预训练，不给专家状态或专家轨迹添加噪声。
- [ ] 测量噪声仅从TD3强化学习微调/环境交互阶段开始加入；纯TD3从环境交互开始即使用相同含噪量测。
- [ ] 对比“无噪声训练＋辨识器”和“含噪训练＋辨识器”，分别报告TD3与BC-TD3的性能变化。
- [ ] 最终比较含噪训练TD3＋辨识器与含噪训练BC-TD3＋辨识器，以保证行为克隆效果的公平比较。
- [ ] 不将含噪训练的改善归因于辨识器；应将其表述为策略对量测噪声的额外适应能力。

**验收标准：**

- 能判断P0-4中的剩余性能损失是否主要来自Actor输入噪声。
- 若含噪训练收益很小，则保留更简单的无噪声训练方案，避免增加论文方法复杂度。

## 5. P2：时间允许可进一步增强



### P2-1 稀疏正则项消融

**目的：** 验证`\ell_1`软阈值不是无效装饰。

**对比组：**

1. 普通FF-RLS，即`\eta=0`；
2. 稀疏FF-RLS，即`\eta>0`。

- [ ] 比较参数NRMSE和联合任务成功率。
- [ ] 优先测试弱激励场景，因为稀疏正则的理论优势主要针对该情形。
- [ ] 若两者差异很小，应弱化论文中关于稀疏项性能优势的表述。



### P2-2 真值参数上界（Oracle）比较

**目的：** 判断辨识后性能距离理想参数还有多大差距。

- [ ] 增加“BC-TD3＋真值制导矩阵”作为仿真上界。
- [ ] 策略输入和其他传感器通道仍保持与含噪试验一致，只替换制导律所需矩阵参数。
- [ ] 计算辨识方案恢复了多少无噪声/真值参数性能。



### P2-3 域外泛化测试

**目的：** 加强BC-TD3泛化性论证。

- [ ] 将测试范围适度扩展到训练范围之外，例如距离、角度或两枚NCV到达时间差扩大10%至20%。
- [ ] 不在域外测试集上重新训练或调参。
- [ ] 报告成功率随偏离训练域程度的变化。



### P2-4 异构NCV或模型失配

**目的：** 提升工程可信度。

- [ ] 令两枚NCV具有不同速度、比例导引系数或过载上限。
- [ ] 可增加轻微NCV制导参数失配，测试对“NCV性能已知”假设的敏感性。
- [ ] 该项不应挤占核心制导消融和真实含噪实验的时间。



### P2-5 超参数敏感性

- [ ] 只选择关键参数，例如`d^*`、`\rho`、`\eta`和`\sigma_j`。
- [ ] 每个参数取3档，其他参数固定。
- [ ] 重点说明性能是否在一个合理区间内稳定，不追求大规模网格搜索。
